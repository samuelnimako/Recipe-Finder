🍲 Recipe Finder App

A simple Recipe Finder web application built with HTML, CSS, and JavaScript, powered by the TheMealDB API.
Search for meals and discover recipes with detailed information.

🚀 Features
	•	🔍 Search for recipes by name
	•	🍽️ Fetch meals from an external API
	•	📖 View recipe details (ingredients & instructions)
	•	🖼️ Display meal images
	•	⚡ Fast and responsive interface

🛠️ Tech Stack
	•	HTML
	•	CSS
	•	JavaScript
	•	TheMealDB API
